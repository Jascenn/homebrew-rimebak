# homebrew-rimebak

Homebrew tap for [RimeBak](https://github.com/Jascenn/rime-backup) - Rime 输入法配置备份工具。

## Installation

```bash
brew tap Jascenn/rimebak
brew install rimebak
```

## Update

```bash
brew upgrade rimebak
```

## Uninstall

```bash
brew uninstall rimebak
brew untap Jascenn/rimebak
```
